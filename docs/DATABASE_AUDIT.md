## Schema Audit

### notes Table
**Issue:** `embedding_generated` column is a boolean flag, but embeddings are tracked in `note_embeddings` table. Redundant.
**Recommendation:** Remove `embedding_generated` column in future migration.

### note_embeddings Table
**Issue:** Created via raw SQL in `__init__.py`, not SQLAlchemy model.
**Impact:** Can't use `db.create_all()` to create it. Migration scripts can't manage it.
**Recommendation:** Create `NoteEmbedding` model class.

### relationships Table
**Issue:** `unique_constraint` on `(note1_id, note2_id)` only prevents A→B and B→A duplicates. Doesn't prevent A→A self-relationships.
**Current state:** No self-relationships detected.
**Recommendation:** Add check constraint `note1_id != note2_id`.

### tags Table
**Issue:** No tags assigned. Table exists but unused.
**Current state:** Seed data doesn't generate tags. `keyword_service.py` suggests tags but doesn't store them.
**Recommendation:** Assign tags during seeding, or auto-assign from keyword extraction.

5. Add `note1_id != note2_id` check constraint
